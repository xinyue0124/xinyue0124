# assets — 把图片放这里

主页 README 引用了这两张布丁狗，存成对应文件名就能显示：

| 文件名 | 是哪张 | 用在哪 |
|---|---|---|
| `pompompurin-champion.png` | 举奖杯 + 皇冠披风的冠军布丁狗 | 顶部 header |
| `pompompurin-hug.png` | 抱着小伙伴的布丁狗 | 爱好区 |

## 怎么把图存进来
1. 在聊天里**右键 / 长按这两张图 → 保存图片**到电脑
2. 重命名成上表的文件名，拖进这个 `assets/` 文件夹
3. 提交推送：
   ```bash
   git add . && git commit -m "add pompompurin art" && git push
   ```

> 注意版权：自用个人主页一般 OK，别商用。图保持 < 2–3MB。
